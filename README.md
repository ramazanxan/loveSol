# 💌 Приглашение на свидание

- `index.html` — страница для неё: стена цветов → вопрос с убегающей кнопкой «Нет» → приглашение.
- `admin.html` — твоя панель (PIN по умолчанию `1402`, меняется в начале скрипта в `admin.html`).

## Как пользоваться
1. Выложи папку в интернет (см. ниже).
2. Открой `https://<твой-сайт>/admin.html`, введи PIN, заполни дату, время, место и т. д.
3. Нажми «Создать ссылку» → «Скопировать» → отправь ей.

Все данные зашиты в саму ссылку (после `#i=`), так что сервер не нужен.
Хочешь что-то поменять — заполни форму заново и отправь новую ссылку.
На странице для неё нет ни одной ссылки на админку.

## Как выложить бесплатно
- **Netlify Drop**: зайди на https://app.netlify.com/drop и перетащи туда эту папку. Сразу получишь адрес.
- **GitHub Pages**: создай репозиторий, загрузи файлы и включи Pages в настройках (Settings → Pages).

Локально для проверки: `python -m http.server 5500`, затем открой http://localhost:5500/admin.html
